<h2><br><img src="https://cdn.serilum.com/description/nameplate/about-the-mod.svg" alt="About the mod" width="838" height="64"></h2>
<p><span style="font-size:18px">Random Village Names is a mod which gives all villages in the world a random name chosen from a list. This name is given via a sign in the center of the village, see the description of Areas for more information on how this is done. It'll give your world a bit more immersion. It is possible to remove the sign and rename it, or remove the name altogether by placing an empty sign in its position.<br><br>The Areas mod has specific config options if you'd for example like to remove the "Entering" part of the displayed text.<br><br>You can also remove the automatically generated sign and place your own. Just make sure it's within a 15 block radius of the automated one.<br><br>The names can be changed in the config. You can add your own, or turn off the built-in list to only use yours. It's also possible to use each name only once, or to place the sign a few blocks underground so it can't be broken by accident.</span></p>

<p>&nbsp;&nbsp;&nbsp;<span style="font-size:18px">All available config options:</span></p>
<div class="spoiler" style="margin-left:10px;padding-left:10px">
<p><span style="font-size:14px"><strong>customVillageNames</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default []</span><br><span style="font-size:13px">Your own village names, one per line in the config screen. A village gets a random name from this list, together with Collective's names when 'useCollectiveVillageNames' is enabled.</span><br><br><span style="font-size:14px"><strong>useCollectiveVillageNames</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default true</span><br><span style="font-size:13px">Whether villages can also get a name from Collective's built-in list, which is editable in ./config/serilum/collective/area_names.json.</span><br><br><span style="font-size:14px"><strong>useEachNameOnce</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default false</span><br><span style="font-size:13px">If enabled, a village name is only used again once every name has been given to a village in that dimension.</span><br><br><span style="font-size:14px"><strong>placeSignsUnderground</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default false</span><br><span style="font-size:13px">If enabled, the village name sign is placed underground below the village center, where it can't be broken by accident. Areas still finds it.</span><br><br><span style="font-size:14px"><strong>undergroundSignDepth</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default 3, min 1, max 10</span><br><span style="font-size:13px">How many blocks below the surface the sign is placed when 'placeSignsUnderground' is enabled.</span></p>
</div>
